### Stack

Backend em NestJS e TypeScript. Frontend em Vue 3 com Quasar ou Nuxt. PostgreSQL e MySQL,
filas com Redis e SQS, observabilidade com OpenTelemetry e Prometheus, autenticação com
Keycloak. Deploy em Docker e Kubernetes.
